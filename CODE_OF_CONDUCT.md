# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant], in full
and without modification. The canonical text at that link is the governing
document; this file records the adoption and the parts a code of conduct cannot
supply on its own — who to contact and how enforcement works here.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

The Contributor Covenant is published under [CC BY 4.0][licence].

[licence]: https://creativecommons.org/licenses/by/4.0/

## Where it applies

All project spaces — issues, pull requests, discussions, commit messages, review
comments — and any space where someone is representing the project publicly.

## Reporting

Report to the maintainer, using the contact on their GitHub profile. Reports are
handled privately. The reporter's identity is not disclosed to the person
reported, or to anyone else, without the reporter's agreement.

There is currently one maintainer, which means a report about the maintainer has
nowhere independent to go. That is a real gap and it is stated rather than
hidden. Until governance broadens (see [GOVERNANCE.md](GOVERNANCE.md)), anyone
uncomfortable reporting to the maintainer should raise the matter publicly in an
issue, or take it to the foundation this project intends to join.

## Enforcement

The Contributor Covenant's four-step ladder applies: correction, warning,
temporary ban, permanent ban. Enforcement actions and their reasons are recorded
privately; aggregate counts are published annually if any occur.

## What this is not for

Technical disagreement is not a conduct problem. Arguing that a field is wrong,
that a mapping would fail an audit, or that the whole model is misconceived is
the contribution this project most wants, and [CONTRIBUTING.md](CONTRIBUTING.md)
says so. Being wrong is not misconduct. Being unpleasant about someone else
being wrong is.

The distinction matters because codes of conduct are sometimes used to make
uncomfortable technical criticism go away. That is not what this one is for, and
an enforcement action taken on those grounds would be a misuse of it.
