# 1. Record architecture decisions

Date: 2026-01-08

## Status

Accepted

## Context

We keep making architectural choices that nobody can reconstruct six months
later. The team has grown from one squad to four in under a year, and the same
questions are being reopened in parallel.

## Decision

We will record architecturally significant decisions as ADRs in `doc/adr`,
using the format described by Michael Nygard.

## Consequences

Decisions become reviewable. The cost is a short document per decision, written
by whoever proposes it.
